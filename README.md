# HP Laptop Linux & SSD Upgrade

## Project Overview

This project documents a hands-on upgrade and Linux installation on an older HP laptop. The goal was to improve the performance of aging hardware and gain practical experience with computer hardware, storage replacement, operating systems, and troubleshooting.

## Work Performed

- Opened and inspected the laptop hardware
- Identified the installed RAM and storage components
- Removed the original 2.5-inch SATA hard drive
- Installed a 256GB 2.5-inch SATA SSD
- Installed and tested Linux Mint
- Tested additional Linux distributions
- Verified the laptop booted and operated correctly after the upgrade
- Used the rebuilt laptop as part of a multi-computer home lab environment

## Skills Demonstrated

- Laptop disassembly and reassembly
- HDD/SSD replacement
- SATA storage identification
- Operating system installation
- Linux configuration
- Hardware troubleshooting
- Boot and installation media
- System testing and verification

## Result

The older laptop was successfully upgraded from a mechanical hard drive to an SSD and configured as a functional Linux system for continued learning and home lab use.
